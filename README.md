# SIDEY Homebrew Tap

Official Homebrew tap for the macOS build of [SIDEY](https://github.com/sidey-app/SIDEY), an ambient overlay messenger for private groups of close friends.

## Requirements

- Apple Silicon (`arm64`)
- macOS 26 Tahoe or later

## Install

```sh
brew install --cask sidey-app/tap/sidey
```

## Update

```sh
brew upgrade --cask sidey-app/tap/sidey
```

SIDEY also uses Sparkle for signed in-app updates.

## Uninstall

```sh
brew uninstall --cask sidey-app/tap/sidey
```

Uninstalling the app does not remove SIDEY preferences, account credentials, or other user data.
